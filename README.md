# EFU: Enforcing Federated Unlearning via Functional Encryption

A server should not silently drop an unlearning update from the agreed federated aggregation. EFU binds encrypted updates to authorized aggregation and lets clients submit learning or unlearning updates through the same protocol. Its experiments measure the trade-off between forgetting selected information and retaining model utility.
